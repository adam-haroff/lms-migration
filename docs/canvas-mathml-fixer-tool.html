Canvas MathML Fixer

Paste the code that triggers Canvas’s Unexpected text node math error. This tool extracts the real equation from the broken WIRIS payload and returns:

  • corrected MathML for Canvas
  • a best-effort LaTeX version for the Equation Editor
Warning: the LaTeX output is a best-effort conversion. Faculty should still test the result in Canvas before using it in a live assessment.
Static client-side page No backend required Can be uploaded to ordinary web hosting

Input

Paste a broken payload, then click Repair.
What this tool is looking for

It looks for WIRIS JSON payloads where the real equation is stored in a "math" field as HTML-escaped MathML. It then decodes that field and returns the inner <math>...</math>.

Output

LaTeX caveat

This LaTeX is generated from the decoded MathML. Most arithmetic and algebraic expressions should convert well, but complex layout, tables, some operator semantics, and some WIRIS-specific structures may need manual review in the Canvas Equation Editor.
